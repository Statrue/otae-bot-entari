# 终末地账号 UI 复刻规格

更新时间：2026-07-15

## 目标

基于用户提供的游戏内个人名片、影拓丰碑关卡页和危机合约结算页，建立三套可替换数据、可输出 PNG、可继续接入 Bot 的 16:9 HTML/CSS 模板。

复刻对象是视觉语言、信息比例和布局逻辑，不把参考截图作为整页背景，不保留截图中的原账号数据。所有人物、奖章、装备、武器、活动和敌人素材来自当前森空岛 API 响应。

## 共同画布

- 危机合约与影拓丰碑输出尺寸：`1920 × 1080`。
- 个人名片从原始 `1920 × 1080` 坐标系中仅裁掉顶部 `82px` 和左侧 `220px`，输出 `1700 × 998`；内部元素不缩放、不拉伸、不重新分配比例。
- 画面密度：桌面游戏 HUD，不使用普通网页导航、卡片栅格或移动端组件。
- 字体：标题和正文使用随插件打包的 `HarmonyOS Sans SC`，数字/HUD 使用 Bahnschrift 与 Arial Narrow 近似游戏中的 Novecento/Iosevka 窄体观感。
- 图标：个人页角色职业、属性和潜能角标全部使用本机游戏资源中提取并固化到 `plugins/endfield/assets/ui/` 的原始 PNG；危机指标继续使用森空岛/Warfarin 返回的真实指标图源。
- 共同纹理：斜向扫描纹、细网格、技术标线、重复刻度、局部噪点感。
- 共同形状：矩形、切角、细边框、短圆角；仅游戏内按钮和浮层使用较大圆角。
- 共同层级：官方资源图作为场景层，半透明色幕作为氛围层，信息面板作为 HUD 层。

## 个人名片

- 左侧约 40%：头像、角色名、等级、主线、三项收藏统计和地区等级。
- 右侧约 35%：奖章展示条、四名展示干员和状态短句。
- 中部保留大面积场景透气区，避免普通 Dashboard 的均匀分栏。
- 主色为煤灰、雾白和荧光绿；橙色只用于头像框和少量警示。
- 森空岛未提供参考截图中的完整名片背景，因此个人页保留最初版绿色场景回退；头像、干员、奖章和小图标仍使用真实资源。
- 奖章槽位按 API 展示位交错映射：奇数位在上层、偶数位在下层，形成上下紧贴的蜂窝排列。
- 奖章背景按游戏原始三层结构组合：左侧 `deco_friend_card_medal_05` 圆环/立方体装饰、中央单层 `bg_friend_card_medalentry` 浅色凹槽，以及右侧 `bg_friend_card_medal` 黄色分界与深色凹槽；中央槽位与实际奖章使用同一定位基准。
- 头像下方白色圆形按钮与右下主题操作组不进入最终输出。

## 影拓丰碑

- 左侧固定关卡序列，选中项白底反相。
- 右上为当前关卡名、推荐等级和关卡描述。
- 右中为机制特性，右下按参考图使用折叠敌方情报、最佳记录和挑战状态；API 不提供奖励预览时不伪造奖励。
- 主色由主题图决定，叠加紫灰和暗红色幕；通过状态使用绿色窄条。

## 危机合约

- 左侧约 48%：行动成功、指标、用时、指标矩阵和奖章提示。
- 右侧约 46%：四名干员纵向大卡、武器和四装备槽。
- 主色为高饱和危机红、炭黑和冷灰紫，黄色仅用于指标和装备等级。
- 结算页强调大数字和硬分区，不使用柔和阴影或玻璃拟态。
- 零额外潜能直接使用官方 `potential_0` 星标/单黄色杠图；不自制横杠或暗化星标。
- 结果数值区保留小型前景图标，并叠加同源深色大水印；武器下方四件历史装备必须完整显示。
- 最终输出移除左上“行动结束”、干员职业角标、右下三按钮以及左下延迟/UID，仅保留底部装饰刻度。

## 数据边界

- 主页显示公开游戏 UID（`roleId`），不显示森空岛内部用户 ID、认证凭据或绑定响应中的其他敏感字段。
- 角色展示遵循 `config.charIds` 顺序，缺失时按等级和稀有度回退。
- 奖章展示遵循 `achieve.display`，并按等级/镀层选择图标。
- 影拓丰碑优先选择当前活动主题，并选择一个困难关卡作为复刻主视图。
- 危机合约先用 `bestRecord.id` 请求 `/api/v1/game/endfield/card/crisis-contract/record`，角色名和职业等静态元数据按 `charId` 补齐，但武器、三词条等级、装备、等级和潜能必须使用历史记录快照，禁止回填当前配装。
- 所有远程资源加载失败时保留布局，不让整页渲染失败。
